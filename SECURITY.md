# Security policy

## Supported versions

Only the latest release and the `main` branch are supported. Security fixes are made on `main` and ship in the next release.

## Reporting a vulnerability

Do not report security problems in a public issue, pull request or discussion. Report them privately through GitHub:

1. Open the **Security** tab of the repository.
2. Choose **Report a vulnerability**.
3. Fill in the form.

## What to include

- The affected file or path, and the commit or branch you tested.
- The steps to reproduce the problem, with the smallest input that triggers it.
- What an attacker can do with it: what data or action is exposed, and whether the attacker must be signed in.
- Any proof of concept or log output, with secrets removed.

## Demo data

The product, reference and contact data in this repository is fictional. Tanyeri is a fictional lighting brand, and the demo contact details are made up. A finding that involves only this demo data is still useful, but please say so in the report.

## Response

Every report is read and answered as soon as possible. There is no fixed response time.
