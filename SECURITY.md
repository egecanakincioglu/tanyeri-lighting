# Security policy

## Supported versions

Only the `main` branch is supported. There are no released versions yet; once the rewrite produces one, this section will list it.

## Reporting a vulnerability

Please do not report security problems in a public issue, pull request or discussion. Report them privately through GitHub:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Fill in the form.

## What to include

- The affected file or path, and the commit or branch you tested.
- The steps to reproduce the problem, with the smallest input that triggers it.
- What an attacker can do with it: what data or action is exposed, and who needs to be logged in.
- Any proof of concept or log output, with secrets removed.

## Demo data

The product, reference and contact data in this repository is fictional. Tanyeri is a fictional lighting brand, and the demo contact details are made up. A finding that only involves this demo data is still useful, but please say so in the report.

## Response

I will read every report and answer it as soon as I can. I do not promise a fixed response time.
