# v0.7.0 — Product details and a new admin panel

> **Products have a description and technical values, every picture can have a description, and the admin panel has a new layout and a new home screen.** **43 commits** since v0.6.0. 3 migrations. The release also adds blog redirects for changed slugs, dated sitemap entries, real project photos and a set of fixes. The live site stays out of search indexes until 1.0.0.

This release fills in the product pages, improves the content that search engines and screen readers read, and redesigns the panel. Three migrations add the new columns and one table.

---

# Products
- A product has an optional description in Turkish and English. It is two to three sentences, 500 characters at most, and must be given in both languages or in neither.
- A product has four optional technical values: luminous flux, colour temperature, CRI and IP. Each is a short text with its unit, such as `1050 lm` or `3000 K`, 20 characters at most.
- The product page shows the saved description and one row for each value that is filled in. An empty value leaves its row off. Without a saved description, the page keeps the text built from power, size, colour and material.
- The product form in the panel has fields for the description and the four values.
- The demo products have descriptions and values. They are fictional.

# Image descriptions
- Six content types now store a picture description in both languages: services, work areas, references, promo boards, catalogs and the home banner. The site uses it as the alternative text of the picture.
- The panel forms have a field for it. The demo seed describes every demo picture in both languages.

# Blog and search
- When an article slug changes, the old address answers with a permanent redirect to the new one. This replaces the limit from v0.6.0.
- A sitemap entry takes its `lastmod` from the content the page shows. The home page, services, projects, references, catalogs, the product list and the blog list use the newest change of their items.
- The language switch in the header keeps the query string, so a product list filtered by category stays filtered in the other language.

# Public pages
- The demo about and vision texts are longer, with headings, lists and links to site pages and blog articles. The vision text is left-aligned.
- The projects page shows one project per row. The demo has two projects, each with a real before and after photo pair.
- Service and reference cards have a hover effect.
- The demo catalog PDFs have a title and an author.

# Admin panel
- The menu, the top bar and the account block are redesigned. Page headers have a clearer hierarchy.
- The panel home is a daily overview. It shows counts, a chart of visits for the last 30 days, the five latest messages, the top countries and a list of content that is still missing: products without a description or a technical value, blog drafts and pictures without a description.
- List rows are lighter. The title links to the edit page, edit is the main action and delete is an icon button. An empty list shows a button to create the first item.
- Forms end in a sticky bar with save, cancel and the status message.
- Turkish and English fields sit together in a bordered group.
- The upload area has a dashed preview with replace and remove buttons.
- The statistics table follows the same list style.
- The demo seed adds five fictional contact messages so the overview has content.

# Fixes
- The messages list uses the visible text as the link name.
- The banner target list has a label for the vision page.
- The site audit no longer reports an SVG source as larger than twice the display size, because an SVG scales without extra bytes.

# Upgrade note
- On a demo site, run `pnpm db:seed:demo` after deploying so the new product details, image descriptions, projects and messages exist.

# Known limits
- The live site stays `noindex` until 1.0.0.
- The demo content is written for a fictional brand. A real site replaces it in the panel.

## Technical notes
- Migrations (3), applied by the build with `prisma migrate deploy`:
  - `20261103100000_product_details`: adds `descriptionTr`, `descriptionEn`, `luminousFlux`, `colorTemperature`, `cri` and `ip` to `product`. All default to an empty string.
  - `20261103110000_image_descriptions`: adds `imageAltTr` and `imageAltEn` to `reference`, `catalog`, `homeBanner`, `promoBoard`, `applicationArea` and `service`. Both default to an empty string.
  - `20261103120000_blog_slug_redirect`: creates the `blogPostSlugRedirect` table with a unique index on `oldSlug`. A row is deleted with its article.
- `pnpm db:seed:demo` is not part of the build. Run it separately on a demo site.
- The demo seed now writes two projects. The three earlier demo projects are replaced by the two photographed ones.
- The panel home counts missing content with `getMissingContent` in `src/server/admin/missing-content.ts`. The visits chart is server-rendered CSS bars with no client script.
- Sitemap dates come from `listContentDates` in `src/server/content/content-dates.ts`, one newest-date query per table.
- The site audit skips the upper image size bound for SVG sources.
- Tests cover the new content fields, the redirects, the sitemap dates, the missing-content counts, the panel home and the form components.
