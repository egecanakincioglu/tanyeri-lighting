# v0.6.0 — Blog

> **The site has a blog: a list page and article pages in Turkish and English, a panel screen to write the articles, and six demo articles about lighting.** **10 commits** since v0.5.0. 1 migration. The release adds the article data model, the public pages with structured data and sitemap entries, the panel screens and the demo articles. The live site stays out of search indexes until 1.0.0.

This release adds the blog on top of the page set from v0.5.0. Articles are stored in both languages, shown only when published, and edited in the panel. The demo seed writes six articles so a demo site has content from the first start.

---

# Public pages
- The blog list is at `/tr/blog` and `/en/blog`. It shows eight articles per page, newest first, with a picture, title, date and summary.
- An article page is at `/<locale>/blog/<slug>`. The slug is the same in both languages. The page shows a breadcrumb, the title, the date, the description, the picture and the text, followed by links to up to two other articles and a link back to the list.
- A draft, an article dated in the future and an unknown slug answer 404.
- The language links in the header switch between the two versions of the same article.
- Blog is a menu entry in the header and the footer. Its page title and description are editable in Page Info.
- The home page banner can link to the blog page.

# Search and structured data
- The title, description and canonical address of an article come from its saved fields. The page has language alternates and Open Graph data of type `article` with the publication and modification times.
- Each article page has `Article` structured data with the organization as author and publisher, and `BreadcrumbList` data that matches the visible breadcrumb.
- The sitemap lists every published article in both languages. The `lastmod` value comes from the last change of the article. The blog list takes the date of the newest article.

# Panel
- The Blog screen lists the articles, drafts first. A form edits the title, page description, summary, text and picture description in both languages, plus the image, the slug and the publication date.
- The slug follows the Turkish title until it is edited by hand.
- An empty publication date keeps the article as a draft. A date in the future publishes the article on that day.
- The text is written in limited Markdown: paragraphs, headings, bold and italic text, links and lists. Raw HTML and images are dropped. Headings start at level 2 because the page owns the only level 1 heading.
- A replaced or deleted picture is removed from the file store. Demo mode refuses writes.
- The dashboard shows the number of articles.

# Image loading
- The first picture of the list and the picture of an article load at once. The other pictures on the list load lazily.
- The demo pictures are 480 px wide, so the article picture is shown at 240 CSS px and the list thumbnails at 192 px (112 px on phones).

# Demo articles
- The demo seed writes six articles in both languages, dated from June to October 2026:
  - Where are track spots used? Types and planning
  - What is linear lighting? Types and how to choose
  - How to choose a recessed spot: size, angle and glare
  - How many lux for an office? EN 12464-1 values
  - Outdoor lighting and IP ratings explained
  - How much does an LED upgrade save? A worked example
- Each article links to a matching product category and to the contact page of the demo site.
- The articles are demo content written for a fictional brand. The seed and the pages do not list sources for them. The LED example uses hypothetical numbers. The project does not present the texts as the advice of a real company.

# Upgrade note
- On a demo site, run `pnpm db:seed:demo` after deploying so the articles exist. Without it, the blog list is empty.

# Known limits
- A changed article slug leaves no redirect. The form warns that links to the old address break.
- The live site stays `noindex` until 1.0.0.
- The articles are demo content for a fictional brand. A real site replaces them in the panel.

## Technical notes
- Migrations (1), applied by the build with `prisma migrate deploy`:
  - `20261103090000_blog_post`: creates the `blog_post` table with bilingual title, description, summary, text and picture description columns, a unique index on `slug` and an index on `publishedAt`.
- `pnpm db:seed:demo` is not part of the build. Run it separately on a demo site.
- A published article is one with a `publishedAt` value that is not null and not in the future. Every public read uses this one filter.
- Limits per field: slug 80 characters, title 120, page description 320, summary 320, text 50000, picture description 200.
- The site audit lists the blog pages. Tests cover the content service, the panel actions, both public pages, the sitemap, the structured data and the demo seed.
