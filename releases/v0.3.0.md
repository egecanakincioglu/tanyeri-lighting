# v0.3.0 — Public site

> **The first public version of the Tanyeri site, in Turkish and English.** **67 commits** since v0.2.0. 1 migration. The pages, the catalog viewer, the contact form and the administrator sign-in are in place. The content comes from fictional demo data, and the live site stays out of search indexes until 1.0.0.

This release builds the visitor-facing site on the server foundation from v0.2.0. It adds the page layout, all public pages, the catalog viewer, the contact form and the sign-in page for administrators. The admin content screens are not part of this release.

---

# Design
- The layout follows the earlier site, with one light theme.
- Figtree is self-hosted, so no font request leaves the site.
- The logo artwork is part of the header, the footer and the icons.
- The header and the footer are redesigned.
- Addresses are localized: the Turkish and the English site each show the address in its own language.

# Pages
- Home, about, vision, services, contact, privacy and terms.
- Products with category tabs and pagination, and a product page.
- Projects, with a before and after slider.
- References and catalogs.
- A not-found page that keeps the site layout.

# Catalogs
- Catalogs appear as a grid of cover cards. A new `coverImage` column holds each cover.
- A page-flip viewer opens a catalog. Its code loads only when a visitor opens a catalog.
- `react-pageflip` and `pdfjs-dist` are new dependencies.

# Contact
- The contact form is a Server Action and works without JavaScript.
- In demo mode the message is shown back to the sender and is not saved.
- A product page can open the form with the product already filled in.

# Demo
- Fictional demo content: products, projects, references, a catalog and photos.
- `pnpm db:seed:demo` loads the demo content into the database.
- A demo notice band tells visitors that the content is fictional.

# Administrator sign-in
- A sign-in page, a link in the footer and a sign-out action.
- A protected panel page for signed-in administrators.
- Content screens are not available yet.

# Icons and sharing
- Site icons and a web app manifest.
- A default image for link previews.

# Quality gates
- The site audit runs against a seeded database in demo mode, so it checks pages with real content.
- The image rule measures real pixels. Full-bleed images are capped at 1920 px.
- Admin screens skip Lighthouse.

# Known limits
- There are no admin content screens yet.
- SEO work is still to come: sitemap, canonical addresses and structured data.
- The live site stays `noindex`.
- Uploaded PDF files are not yet allowed by the viewer's connection rules.
- The vision page has no meta description.
