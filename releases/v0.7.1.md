# v0.7.1 — Security update and panel fixes

> **Next and its ESLint config move to 16.4.5, which fixes seven moderate advisories, and three admin panel behaviours are fixed.** **6 commits** since v0.7.0. No migrations.

This release updates Next.js for published security advisories. It also fixes how unread counts and keyboard focus behave in the admin panel.

---

# Security
- `next` and `eslint-config-next` move from 16.4.3 to 16.4.5.
- Version 16.4.5 fixes seven moderate advisories published on 2026-11-03: GHSA-mfr8-8qww-v76h, GHSA-vc7v-qv4w-wrv8, GHSA-vvgp-ww4w-46vf, GHSA-rhh4-g77r-r9qj, GHSA-pc58-hwjq-p385, GHSA-7qx7-33qx-rqx2 and GHSA-f3mh-rxg3-f5g2.

# Admin panel
- Opening a message updates the unread count in the menu right away. The read mark moved from the page request to a server action. The demo does not mark messages as read.
- After a row is deleted in a list, the list shows "Deleted." and focus moves to the main region. The earlier order message no longer stays on screen. This also holds when the last row goes and the empty state shows.
- In the featured products picker, focus stays usable after a remove or an add. It goes to a neighbouring remove button or to the search input. When the list becomes full, it goes to the remove button of the new row.
