Font used by the site. Figtree-Variable.woff2 is a subset of an OFL font, served from
this folder through next/font/local. Nothing is fetched from the internet.

Figtree-Variable.woff2
  Source: https://github.com/google/fonts, commit 6c1dbe27dcf7d817d4b62cec033ba77fa8e2a5ec,
          ofl/figtree/Figtree[wght].ttf
  License: OFL-Figtree.txt (no Reserved Font Name is declared; the name is kept).
  Axes: wght 400-700 kept (the source range is 300-900).
  Coverage: Latin plus full Turkish (ğ Ğ ş Ş ı İ ç Ç ö Ö ü Ü). The font has no glyph for the
  lira sign U+20BA, which falls back to the system font.
  Steps:
    python -m fontTools.varLib.instancer "Figtree[wght].ttf" wght=400:700 -o figtree-limited.ttf
    pyftsubset figtree-limited.ttf --unicodes="$UNICODES" --layout-features="$FEATURES"
      --flavor=woff2 --no-hinting --desubroutinize --name-IDs="*" --output-file=Figtree-Variable.woff2

UNICODES=U+0020-007E,U+00A0-017F,U+0307,U+2010-2015,U+2018-201E,U+2020-2022,U+2026,
         U+2030,U+20AC,U+20BA,U+2122,U+2190-2193,U+2212
FEATURES=kern,liga,calt,locl,ccmp,mark,mkmk,tnum,case

Logo lettering (public/brand/logo-header.svg, public/brand/logo.svg): outlined from Parisienne (OFL).
The tagline in logo.svg is outlined from Poppins Light (OFL).
