Fonts used by the site. Both files are subsets of OFL fonts, served from
this folder through next/font/local. Nothing is fetched from the internet.

Archivo-Variable.woff2
  Source: https://github.com/Omnibus-Type/Archivo, commit 211127690e8ff106c36c935f7e5e697114cff103,
          fonts/variable/Archivo[wdth,wght].ttf (version 2.001)
  License: OFL-Archivo.txt (no Reserved Font Name is declared; the name is kept).
  Axes: wght 400-800 kept, wdth fixed at 100.
  Steps:
    python -m fontTools.varLib.instancer "Archivo[wdth,wght].ttf" wdth=100 wght=400:800 -o archivo-limited.ttf
    (same through fontTools.varLib.instancer.instantiateVariableFont when run from a script)
    python -m fontTools.subset archivo-limited.ttf --unicodes="$UNICODES" --layout-features="$FEATURES"
      --flavor=woff2 --no-hinting --desubroutinize --name-IDs="*" --output-file=Archivo-Variable.woff2

TanyeriMono-Regular.woff2
  Source: https://github.com/IBM/plex, release @ibm/plex-mono@2.5.0,
          ibm-plex-mono/fonts/complete/ttf/IBMPlexMono-Regular.ttf (version 2.005)
  License: OFL-IBMPlexMono.txt. The license reserves the name "Plex", and a subset is a
  modified version, so the family is renamed: name IDs 1, 3, 4 and 6 are set to
  "Tanyeri Mono" / "TanyeriMono-Regular", and the trademark record (ID 7) is removed.
  The copyright notice (ID 0) and the license records (IDs 13, 14) stay unchanged.
  Steps:
    python -m fontTools.subset IBMPlexMono-Regular.ttf --unicodes="$UNICODES" --layout-features="$FEATURES"
      --flavor=woff2 --no-hinting --desubroutinize --name-IDs="*" --output-file=plexsub.woff2
    then rename the name records above with fontTools.ttLib and save as woff2.
